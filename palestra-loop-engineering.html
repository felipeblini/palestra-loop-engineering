A especificação

É o contrato entre você e a IA, escrito antes de qualquer código:

  • Um PRD gerado através de um briefing
  • As regras inegociáveis do negócio
  • Stack do projeto
  • etc...

O Loop do Ralph

Não é o mais esperto da turma, mas é persistente e não desiste nunca.

Recebe a mesma tarefa de novo e de novo até terminar.

Aprende com os erros, se corrige e tenta de novo.

project-phases.md

## Fase 1
Cadastro de clientes com nome e WhatsApp.
Pronto quando: cadastro, edito e busco.

## Fase 2
Agenda por profissional.
Pronto quando: ninguém marca o mesmo
horário com a mesma profissional.

loop-ralph.mjs

const spec = readFileSync("project-phases.md", "utf8");
const fases = spec.split(/^## Fase \d+/m).slice(1);
const MAX_TENTATIVAS = 5;

for (const [i, fase] of fases.entries()) {
  let pronto = false;

  for (let t = 1; t <= MAX_TENTATIVAS; t++) {
    // Cada chamada é um Claude "zerado": mesa limpa
    execSync("claude -p", {
      input: `Implemente esta fase:\n${fase}`
    });

    pronto = juiz(fase); // quem decide não é o Ralph
    if (pronto) break;
  }

  if (!pronto)
    throw new Error(`Fase ${i + 1} travou. Chama o humano.`);
}

O JUIZ

judge.mjs

function juiz(fase) {
  // 1. travas baratas primeiro
  if (testesAlterados()) return false;  // hash
  if (foraDoEscopo(fase)) return false;
  if (testeDesligado()) return false;  // .skip

  // 2. o projeto roda de verdade?
  try { execSync("npm run lint && npm test && npm run build"); }
  catch { return false; }

  // 3. segunda opinião: outro agente, contexto limpo
  const nota = execSync("claude -p", {
    input: `Você é um revisor de código e QA.
Confira os critérios e responda só
1 para APROVADO ou 0 para REPROVADO.\n${fase}`
  }).toString().trim();

  return nota === "1";
}
